# Project Design Registry — Digest Room (Flip the Switch)
Comparison vs the three most recent rulebook-era projects, from recorded design
descriptions (previous project screenshots were not on file for inspection — noted honestly).

## This project
- Concept: "The room is the desk" — chat timeline as workflow.
- Palette: deep slate + signal lime (agent-only) + warm off-white; no gradients/glow.
- Type: system sans + mono log voice. Layout: room list | timeline hero | tasks rail.
- Signature interaction: ✅ reaction claim -> in-thread agent confirmation -> rail task card.
- 3D: functional CSS depth pipeline (Open -> Claimed -> Due 48h -> Expired),
  live counts, clickable stages, reduced-motion flat fallback. Exception
  withdrawn 2026-11-04 — depth now does real work, not decoration.

## Compared projects
1. CageCheck (Vultr) — paper / ink / stamp aesthetic, light paper background, stamped
   receipts, deterministic guard UI. DIFFERENCE: Digest Room is dark console, chat-first,
   lime agent voice; nothing paper-like, no stamps, no receipt metaphor.
2. Spec Ghost (Kiroween) — near-black brown + candlelight amber, Georgia serif, 860px
   single column, candlelit document feel. DIFFERENCE: Digest Room uses sans + mono, a
   three-column room layout, and a lime signal accent; no serif document feel, no amber
   candlelight, no single-column essay layout.
3. ChatBoss (Codex x TwitchCon) — stream overlay: dark game UI, boss battle HUD, live
   leaderboard, viewer-readable at stream distance. DIFFERENCE: Digest Room is a quiet
   work room, not a spectacle overlay; no HUD bars, no leaderboard, no game art, and its
   agent speaks in a log voice, not battle announcements.
Verdict: recognisably different in concept, palette, type, layout, interaction and motion.
